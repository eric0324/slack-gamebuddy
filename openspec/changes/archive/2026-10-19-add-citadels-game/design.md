## Context

### 規則來源與版本

- 富饒之城（Citadels，Bruno Faidutti，2000）有幾個版本：
  - **原版／經典版（2000、Fantasy Flight 2010 年 Dark City 合輯版）**：8 個角色，建滿 **8 棟**觸發結束；基本建築牌 66 張（另有 14 張打星號的擴充紫卡和 10 個擴充角色，基本遊戲要拿掉）。
  - **Citadels Classic（Windrider 2016 重印）**：同樣 8 個角色，但預設改成 **7 棟**結束（8 棟列為「Classic Variant」），同分改成比最後一輪角色編號。
  - **2016 新版（Z-Man）**：換了一批角色和 30 種紫卡，不採用。
- 使用者指定經典版：**8 個原版角色、建滿 8 棟、基本 66 張建築牌（含 12 張紫卡）**，規則文字以 Fantasy Flight 2010 版規則書為準（查證來源：FFG Citadels rulebook、Windrider Citadels Classic rulebook、Wikipedia「Citadels (card game)」）。
- 使用者原本估計紫卡「約 14 種」；查證後基本遊戲是 **11 種、12 張**（要塞 2 張），14 張是擴充用的星號卡。這裡照基本遊戲做（見 Decisions 1）。

### 經典版規則重點（查證結果）

- **開局**：建築牌洗好每人 4 張，每人 2 金，最年長者拿王冠。金幣無限；手牌沒有上限；金幣數和手牌數是公開資訊。
- **選角**：王冠持有者洗 8 張角色牌，先面朝下隨機棄 1 張（誰都不看），再依人數面朝上棄牌：4 人 2 張、5 人 1 張、6～7 人 0 張。**國王不能被面朝上棄掉**：翻到國王就再翻一張補上，國王洗回去。王冠持有者先祕密選 1 張，剩下的傳給左手邊，依序每人選 1 張；最後剩下的 1 張面朝下棄掉。**7 人**：第 7 位拿到第 6 位傳來的最後 1 張時，也可以偷看開頭面朝下棄掉的那張，二選一，另一張面朝下棄掉。
- **行動**：王冠持有者依編號 1→8 叫號；拿到該角色的玩家翻開角色、進行回合；沒人拿就叫下一號。回合中必須先收集資源：拿 2 金，或抽 2 張建築牌留 1 張、另一張放到牌堆底。之後可以建 1 棟（付建築費用給銀行）。城市裡不能有兩棟同名建築。角色能力每回合限用一次、可以不用，沒有特別寫時機的能力可以在回合中任何時候用；收稅型能力可以在建造前或建造後收，但只能收一次。
- **角色能力**：
  1. **刺客**：說出一個角色殺掉他；被殺的角色被叫到時保持沉默，整個回合跳過。
  2. **盜賊**：說出一個角色；那個角色被叫到翻開時，盜賊立刻拿走他所有金幣。不能偷刺客，也不能偷被刺客殺掉的角色。
  3. **魔術師**：二選一：(a) 和另一位玩家交換全部手牌（自己沒手牌也可以，就是直接拿走對方的）；(b) 把任意張手牌放到牌堆底，再抽同樣張數。
  4. **國王**：每棟貴族（黃）建築收 1 金。被叫到時立刻拿王冠，之後由他叫號，下一輪由他先選角。被殺時一樣跳過回合，但這輪結束後公開身分、照樣拿王冠。沒人選國王時王冠不動。
  5. **主教**：每棟宗教（藍）建築收 1 金。這一輪他的建築不會被軍閥破壞；主教被刺客殺掉時沒有這個保護（Windrider 版明文；FFG 版沒寫例外，Wikipedia 的說明也是被刺殺時失去保護）。
  6. **商人**：每棟商業（綠）建築收 1 金；收集資源後另外多拿 1 金。
  7. **建築師**：收集資源後另外抽 2 張放進手牌；這回合最多可以建 3 棟。
  8. **軍閥**：每棟軍事（紅）建築收 1 金。可以付「建築費用 − 1」金破壞任何一位玩家（包括自己）的一棟建築，被破壞的牌放到牌堆底。不能破壞已經建滿 8 棟的城市。
- **結束**：有人建好第 8 棟時，這一輪打完就結束（城市可以超過 8 棟）。
- **計分**：建築費用總和；五種顏色都有 +3；第一個建滿 8 棟 +4；其他在遊戲結束時建滿 8 棟 +2；紫色建築另外加分。同分時比建築費用總和（只算第 1 項），再比手上金幣。

## Goals / Non-Goals

**Goals:**
- 只用按鈕就能玩完（選角色、收集、能力、建造、結束回合）；頻道不洩漏手牌、選到的角色（翻開前）、面朝下棄掉的角色
- 規則照經典版，數值和原版一致；有人掛機也一定會推進；1 位真人 + bot 可以玩完整局
- 一局約 6～8 輪，30～45 分鐘

**Non-Goals:**
- 不做 2～3 人變體（每人兩個角色）、8 人局
- 不做擴充角色（巫婆、收稅官……）和 14 張星號擴充紫卡、不做 2016 新版角色和紫卡
- 不做「7 棟結束」的短局選項、不做自訂秒數
- 不提供打字的遊戲中指令（只有 new／addbot／removebot／start／cancel／help）

## Decisions

1. **版本取捨**：
   - 結束條件 8 棟（原版），不是 Windrider 重印版預設的 7 棟。
   - 同分處理照 FFG 原版：比建築費用總和，再比金幣；都一樣就並列（2016 系列「比最後一輪角色編號」不採用）。
   - 紫卡用基本遊戲 11 種 12 張，不用 14 張星號擴充卡（使用者說「約 14 種」，需要確認，見 Risks）。
   - 主教被刺殺時失去保護（Windrider 版明文規定，和多數玩家共識一致）。
2. **王冠第一次給誰**：原版是「最年長的玩家」，Slack 不知道年齡，改成**隨機**一位玩家。
3. **座位順序**：加入房間的順序；選角從王冠持有者開始，依座位往下輪。
4. **回合內順序簡化**：
   - **收集資源一定是回合第一步**（拿 2 金或抽牌），之後才能用角色能力、建造。原版允許先發動能力（例如魔術師先換牌再抽），差別不大，換來選單簡單。
   - 商人多 1 金、建築師多 2 張在收集資源後**自動**給。
   - 國王被叫到時**自動**拿王冠。
   - **收稅**（國王／主教／商人／軍閥）用「💰 收稅」按鈕，回合中任何時候按一次；回合結束時還沒收就**自動收**（收稅對玩家只有好處，自動收不會改變策略，只避免忘記）。
   - 軍閥的破壞：收集資源後的任何時候，一回合一次（FFG 版寫「回合結束時」，Windrider 版寫任何時候，選比較好操作的）。
5. **刺客、盜賊可選的目標**：刺客可以選 2～8 號中「沒有面朝上棄掉」的角色；盜賊可以選 3～8 號中沒有面朝上棄掉、也不是被殺的角色。面朝下棄掉的角色不排除（玩家不知道是哪張）；選到沒人拿的角色就是白費。
6. **被刺殺的公告**：叫到被殺的角色時，頻道公告「X 號 <角色> 被刺殺了，跳過」，**不公開是誰**（原版玩家保持沉默）；被殺的國王在這輪結束時公開身分並拿王冠。
7. **盜賊偷錢時機**：被偷的角色被叫到、翻開身分的當下，在他收集資源之前，系統自動把他全部金幣轉給盜賊，頻道公告。
8. **鬼城**：遊戲結束計算五色時，鬼城可以算任何一種顏色；如果鬼城是在**最後一輪**（觸發結束的那一輪，不論在觸發之前或之後）建的，就只算紫色。
9. **魔法學校**：收稅時自動算成對該角色有利的顏色（國王算黃、主教算藍、商人算綠、軍閥算紅）；五色加分時只算紫色。
10. **天文台／圖書館**：用「抽牌」收集資源時，有天文台抽 3 張；有圖書館全部留下；兩棟都有時抽 3 張留 2 張（FFG 規則書明文）。
11. **墓地**：軍閥破壞別人的建築時，墓地的主人（不是軍閥本人、手上至少 1 金）會私下被詢問要不要付 1 金收回那張牌（20 秒，超時不收回）；詢問期間軍閥的回合暫停。墓地自己被破壞時不能救自己。
12. **抽牌堆用完**：抽牌時牌堆不夠就能抽幾張算幾張（0 張也算完成收集）；被棄掉、被破壞的牌放到牌堆底，所以牌堆通常不會真的用完。
13. **安全上限**：為了保證一定會結束，第 **20 輪**結束時還沒有人建滿 8 棟就直接計分（公告「已達 20 輪上限」）；這是原版沒有的規則，正常對局不會碰到（需要使用者確認）。
14. **私密資訊**：手牌、自己選的角色（翻開前）、抽到的牌、魔術師換到的牌、第 7 位看到的面朝下角色，一律用 `ephemeral` 或私訊給本人；頻道只公告動作和公開資訊（金幣、手牌張數、城市、翻開的角色）。
15. **計時**：`DRAFT_MS = 45_000`（每位選角，超時隨機選一張）、`TURN_MS = 90_000`（每個角色回合，超時自動完成：還沒收集就拿 2 金、抽牌選擇中就留第一張、自動收稅、不建造、不用能力，結束回合）、`GRAVE_MS = 20_000`（墓地詢問）。同一時間只有一個 phase 計時器。

### State（草稿，`src/citadels.ts`）

```ts
type Rank = 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8;
interface CPlayer { id: string; gold: number; hand: string[]; city: { card: string; round: number }[]; char?: Rank; }
interface CState {
  game: 'citadels'; channel: string; host: string;
  phase: 'lobby' | 'draft' | 'turn' | 'graveyard' | 'ended';
  players: CPlayer[]; deck: string[];           // deck[0] 是最上面，放回去放到最後
  crown: number;                                // 王冠持有者 index
  round: number;                                // 第幾輪（1 起）
  draft?: { pool: Rank[]; faceUp: Rank[]; faceDown: Rank; order: number[]; at: number };
  calling: Rank;                                // 目前叫到幾號
  killed?: Rank; robbed?: Rank; robber?: string;
  turn?: { player: number; gathered: boolean; drawn?: string[]; ability: boolean; taxed: boolean;
           builds: number; lab: boolean; smithy: boolean; magicianPick?: number[] };
  graveyard?: { owner: string; card: string; warlord: number };
  firstComplete?: string;                       // 第一個建滿 8 棟的人
  lastRound?: number;                           // 觸發結束的那一輪
  seq: number;                                  // 每次叫號 +1，牌桌 ref 和選單過期判斷
  winners?: string[]; timerSeq: number; timers: { phase?: number };
}
```

### Action

`new`、`join`、`leave`、`start`、`cancel`、`addBot`、`removeBot`、`rematch`、`status`（我的狀態）、`pickMenu`、`pick { rank }`、`turnMenu { seq }`、`gather { seq, kind: 'gold' | 'draw' }`、`keep { seq, card }`、`build { seq, card }`、`tax { seq }`、`kill { seq, rank }`、`rob { seq, rank }`、`swap { seq, user }`、`redrawToggle { seq, index }`、`redraw { seq }`、`destroy { seq, user, card }`、`lab { seq, card }`、`smithy { seq }`、`grave { yes }`、`end { seq }`、`timeout { id }`。

### 按鈕與訊息

- 頻道：選角訊息（`ref: citadels:draft:<round>`）附「🎭 選角色」；牌桌訊息（`ref: citadels:<seq>`，每次叫號一則，回合內原地更新）附「🏰 我的回合」「📜 我的狀態」。
- 私下選單（`audience: 'ephemeral'`，`perRow: 4`）：選角清單、回合選單（收集 → 能力／建造／收稅／實驗室／鐵匠鋪／結束回合）、建造清單、目標清單；value 帶 `seq` 擋過期選單。
- 墓地詢問用 `audience: 'user'` 私訊（「付 1 金收回」「不用」）。

### Bot 策略（簡單即可）

`runGame` 的 `afterChange: runBots`：輪到 bot 選角、輪到 bot 的角色、bot 被詢問墓地時立刻處理，規則見 `specs/citadels/bots`。

## Risks / Trade-offs

- [紫卡數量和使用者預期不同] → 經典基本遊戲是 11 種 12 張，不是 14 種；在回報中請使用者確認，要 14 張的話可以從 FFG 星號擴充卡挑 2～3 張加入（原版也有這個做法）
- [20 輪安全上限不是原版規則] → 只為了保證結束；正常一局 6～9 輪就會有人建滿，需要使用者確認
- [一局比較久、Slack 訊息多] → 每次叫號只發一則牌桌訊息並原地更新；沒人拿的角色合併在下一則公告
- [90 秒回合對蓋 3 棟的建築師偏緊] → 常數集中在 `TURN_MS`，之後好調整
- [engine 比較大] → 牌組資料拆到 `src/citadelsCards.ts`，engine 仍放在單一檔案
