# 💎 印加寶藏

一張一張翻探險卡，每一步大家**同時**決定要繼續挖寶還是帶著寶石回營地。貪心的人可能拿最多，也可能遇到第二張同種危險全部泡湯。照官方原版 Incan Gold（Diamant）規則。

- 人數：3～8 人（可以加 bot 補人數）
- 時間：約 10～15 分鐘
- 分類：🎲 心理戰
- 代號：`incan`

## 快速開始

1. 在頻道輸入 `/game incan new` 開房
2. 其他人按「加入」；人不夠可以 `/game incan addbot 2`
3. 房主按「開始遊戲」或輸入 `/game incan start`
4. 每一步按步驟訊息上的「🔦 繼續探險」或「⛺ 回營地」
