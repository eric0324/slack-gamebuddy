# 🚀 星際探險隊：指令

## 斜線指令

| 指令 | 誰可以用 | 說明 |
|---|---|---|
| `/game crew new` | 任何人 | 開房，預設打這個頻道已解鎖的最高關（全破後預設第 40 關） |
| `/game crew start` | 房主 | 開始遊戲，需要 3～5 人 |
| `/game crew level` | 任何人 | 只讓你看到這個頻道已解鎖的關卡（編號、名稱、任務數、特殊規則） |
| `/game crew level <n>` | 房主（開始前） | 改打第 n 關，只能選已解鎖的關卡 |
| `/game crew reset` | 房主（開始前） | 重設這個頻道的進度，會先跳出「⚠️ 確定重設」按鈕，按下才會重設為只解鎖第 1 關 |
| `/game crew cancel` | 房主 | 取消遊戲（不記戰績、不改進度） |
| `/game crew help` | 任何人 | 指令說明 |

`/game crew addbot`：星際探險隊不支援 bot。

## 按鈕

| 按鈕 | 在哪裡 | 說明 |
|---|---|---|
| 加入／離開／開始遊戲 | 房間公告 | 和其他遊戲一樣；房主開始前離開會取消房間 |
| 🃏 手牌 | 分配訊息、牌桌訊息 | 只有你看得到自己的手牌和任務；輪到你時列出可以出的牌 |
| 任務按鈕 | 挑任務訊息 | 輪到你時挑一張任務（60 秒，逾時自動挑第一張） |
| 🙋 要／🙅 不要 | 🎖️ 指揮官指派 | 表態要不要這張任務（公開顯示） |
| 🙋 可以／🙅 不行 | 🎯 單人任務 | 回答能不能包辦全部任務（公開顯示） |
| 玩家按鈕 | 指派／單人任務／隊員失能 | 只有指揮官能按 |
| 📡 通訊 | 牌桌訊息 | 每人每關一次，這墩第一張牌打出前；📴 無線電靜默的關卡沒有這個按鈕 |
| 🔁 轉交任務 | 牌桌訊息 | 5 人局、第 15 關以後、沒有 🎯／🎖️ 的關卡，第一墩出牌前可以轉交一次 |
| 🚀 下一關／🔁 重打 | 結束時 | 就是「再來一局」：只有上一局的玩家能按，按的人是新房主 |

## 計時

| 階段 | 時間 | 逾時 |
|---|---|---|
| 挑任務 | 每次 60 秒 | 自動挑剩下的第一張 |
| 指揮官指派 | 每張 90 秒 | 給任務最少的人 |
| 單人任務選人 | 90 秒 | 第一個回答可以的人，否則指揮官下家 |
| 指定失能 | 90 秒 | 指揮官下家 |
| 每墩開始 | 10 秒 | 通訊時間，不能出牌 |
| 出牌 | 每張 2 分鐘 | 系統代出最小的合法牌 |
