# 🎨 妙語說書人

說書人看自己手上的一張梗圖，給一句提示；其他人從手牌挑一張最符合提示的圖混進去，大家再猜哪張是說書人的。提示要「有人猜得到、但不能所有人都猜到」，好玩就在拿捏。照桌遊 Dixit 的原版規則，牌用梗圖大亂鬥的梗圖庫。

- 人數：3～8 人（不支援 bot）
- 時間：約 20～30 分鐘
- 分類：🎲 心理戰
- 代號：`dixit`

## 快速開始

1. 在頻道輸入 `/game dixit new` 開房
2. 其他人按「加入」
3. 房主按「開始遊戲」或輸入 `/game dixit start`
4. 隨時按頻道訊息上的「🃏 我的手牌」看自己的牌（只有自己看得到）
5. 輪到你當說書人：在手牌選一張，輸入一句提示
6. 不是說書人：在手牌出一張最符合提示的牌，再到投票訊息猜哪張是說書人的

## 牌從哪裡來

梗圖大亂鬥的內建梗圖，加上這個頻道用 `/game meme add <圖片網址>` 投稿的梗圖。牌上只顯示圖片和編號，不顯示梗圖名稱。
