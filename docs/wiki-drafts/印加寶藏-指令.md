# 💎 印加寶藏：指令

| 指令 | 誰可以用 | 說明 |
|---|---|---|
| `/game incan new` | 任何人 | 開房，開房的人是房主並自動加入 |
| `/game incan addbot [數量]` | 房主，開始前 | 加入 bot 補人數（沒寫數量就是 1，最多到 8 人） |
| `/game incan removebot [數量]` | 房主，開始前 | 從最後加入的 bot 開始移除 |
| `/game incan start` | 房主 | 開始遊戲，需要 3～8 人 |
| `/game incan cancel` | 房主 | 取消遊戲（不記戰績） |
| `/game incan help` | 任何人 | 顯示指令說明 |

## 按鈕

- 房間公告：「加入」「離開」「開始遊戲」
- 步驟訊息：「🔦 繼續探險」「⛺ 回營地」（30 秒內選，揭曉前可以改；沒選視為回營地）
- 遊戲結束：「再來一局」（只有上一局的玩家可以按，按的人成為新房主）

遊戲中沒有打字指令，全部用按鈕。
