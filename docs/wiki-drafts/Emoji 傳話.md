# 🔗 Emoji 傳話

傳情畫意（Telestrations）的 Slack 版：把「畫圖」換成「只用 emoji 描述」。每人拿一個題目當自己那條鏈的起點，文字用 emoji 演、emoji 用文字猜，一路傳下去，最後一起看題目怎麼走鐘，再投票選出最佳 emoji 和最神猜測。

- 人數：4～10 位真人（不支援 bot）
- 時間：約 10～18 分鐘
- 分類：🎲 心理戰
- 代號：`emoji`

## 快速開始

1. 在頻道輸入 `/game emoji new` 開房
2. 其他人按「加入」
3. 房主按「開始遊戲」或輸入 `/game emoji start`
4. 每一步按步驟訊息上的「✍️ 作答」，看你拿到的內容並作答
5. 傳完一圈後看每條鏈，按「🎨 投最佳 emoji」「🧠 投最神猜測」投票
