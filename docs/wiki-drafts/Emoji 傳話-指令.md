# 🔗 Emoji 傳話：指令

| 指令 | 誰可以用 | 說明 |
|---|---|---|
| `/game emoji new` | 任何人 | 開房，開房的人是房主並自動加入 |
| `/game emoji start` | 房主 | 開始遊戲，需要 4～10 位真人 |
| `/game emoji send <內容>` | 這一步需要作答的玩家 | 作答，和按「✍️ 作答」一樣；🎨 步只能用 emoji（最多 20 個），🧠 步寫 1～30 字；截止前可以重送 |
| `/game emoji cancel` | 房主 | 取消遊戲（不記戰績） |
| `/game emoji help` | 任何人 | 顯示指令說明 |

Emoji 傳話不支援 bot，`addbot` 會被拒絕。

## 按鈕

- 房間公告：「加入」「離開」「開始遊戲」
- 步驟訊息：「✍️ 作答」（只有自己看到拿到的內容，並打開作答視窗；視窗打不開時改用 `/game emoji send <內容>`）
- 投票訊息：「🎨 投最佳 emoji」「🧠 投最神猜測」（打開只有自己看得到的作品編號選單，按一個就是投票，截止前可以改）
- 遊戲結束：「再來一局」（只有上一局的玩家可以按，按的人成為新房主）
