# 🎨 妙語說書人：指令

| 指令 | 誰可以用 | 說明 |
|---|---|---|
| `/game dixit new` | 任何人 | 開房，開房的人是房主並自動加入 |
| `/game dixit start` | 房主 | 開始遊戲，需要 3～8 位真人 |
| `/game dixit clue <編號> <提示>` | 說書人，說書階段 | 用手牌第幾張給提示（1～50 字），例如 `/game dixit clue 2 薛丁格的貓`；和在「🃏 我的手牌」選牌再輸入提示一樣 |
| `/game dixit cancel` | 房主 | 取消遊戲（不記戰績） |
| `/game dixit help` | 任何人 | 顯示指令說明 |
| `/game meme add <圖片網址> [名稱]` | 任何人 | 投稿梗圖到這個頻道的梗圖庫，妙語說書人和梗圖大亂鬥都會用到 |

不支援 bot：`/game dixit addbot` 會被拒絕。

## 按鈕

- 房間公告：「加入」「離開」「開始遊戲」
- 說書、出牌、投票訊息：「🃏 我的手牌」，只有自己看得到自己的手牌圖片
  - 說書階段的說書人：每張牌一顆編號按鈕，按了會開視窗輸入提示
  - 出牌階段還沒出完的非說書人：每張牌一顆編號按鈕，按了就出牌
  - 其他時候只顯示圖片
- 投票訊息：每張牌一顆編號按鈕（不能投自己的牌，截止前可以改票）
- 遊戲結束：「再來一局」（只有上一局的玩家可以按，按的人成為新房主）

手牌選單過期（換了一輪）時，重新按「🃏 我的手牌」就好。
