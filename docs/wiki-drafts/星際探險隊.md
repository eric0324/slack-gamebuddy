# 🚀 星際探險隊

合作吃墩遊戲（The Crew 的通用機制，關卡全部自編）：大家**不能討論手牌**，只靠出牌和每關一次的「通訊」默契合作，讓指定的人吃下指定的牌。頻道會記住打到第幾關，一關一關往第九行星前進。

- 代號：`crew`
- 人數：3～5 人（不支援 bot）
- 大廳分類：🤝 合作
- 一關大約 5～15 分鐘

## 快速開始

1. `/game crew new` 開房，大家按「加入」
2. 房主按「開始遊戲」（或 `/game crew start`）
3. 挑任務 → 出牌，全程按按鈕完成

🤫 請不要在頻道討論手牌，只靠出牌和通訊溝通。

## 戰績

合作遊戲只記場數和全隊分數，不算勝負：成功時記這一關的關卡編號，失敗記 0 分。所以 `/game stats` 的最高分就是你在這個頻道最高通過的關卡，`/game rank crew` 依最高通過關卡排名。取消的遊戲不記錄。
