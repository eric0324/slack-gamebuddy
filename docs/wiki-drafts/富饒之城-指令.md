# 🏛️ 富饒之城：指令

## 斜線指令

| 指令 | 誰可以用 | 說明 |
|---|---|---|
| `/game citadels new` | 任何人 | 開房（一個頻道同時只能有一局） |
| `/game citadels addbot [數量]` | 房主（開始前） | 加入 bot，沒寫數量就是 1；最多加到 7 人 |
| `/game citadels removebot [數量]` | 房主（開始前） | 從最後加入的 bot 開始移除 |
| `/game citadels start` | 房主 | 開始遊戲，需要 4～7 人 |
| `/game citadels cancel` | 房主 | 取消遊戲，公告目前每人的建築費用總和（不記戰績） |
| `/game citadels help` | 任何人 | 指令說明 |

遊戲中沒有打字指令，全部用按鈕。

## 按鈕

| 按鈕 | 在哪裡 | 說明 |
|---|---|---|
| 加入／離開／開始遊戲 | 房間公告 | 和其他遊戲一樣；房主開始前離開會取消房間 |
| 🎭 選角色 | 選角訊息 | 輪到你時私下列出還能選的角色和這輪面朝上的棄牌 |
| 🏰 我的回合 | 牌桌訊息 | 叫到你的角色時私下列出現在能做的事：💰 拿 2 金／🃏 抽牌 → 角色能力、🔨 建造、💰 收稅、🧪 實驗室、⚒️ 鐵匠鋪、✅ 結束回合 |
| 📜 我的狀態 | 牌桌訊息 | 隨時私下看自己的手牌（紫卡附效果）、金幣、這輪的角色和城市 |
| 付 1 金收回／不用 | 私訊 | 有墓地的玩家在軍閥破壞建築時被詢問 |
| 再來一局 | 結束時 | 只有上一局的玩家能按，按的人是新房主 |

角色能力按鈕：🗡️ 刺殺、🦹 偷竊、🔄 換手牌、♻️ 棄牌重抽（先點要棄的牌，再按「確認重抽」）、💥 破壞。選單過期（上一個回合的、或已經做過的動作）會請你重新按「🏰 我的回合」。

## 計時

| 階段 | 時間 | 逾時 |
|---|---|---|
| 選角 | 每人 45 秒 | 隨機選一張剩下的角色 |
| 角色回合 | 90 秒 | 還沒收集就拿 2 金、抽牌選擇中就留第一張、自動收稅，不建造，結束回合 |
| 墓地詢問 | 20 秒 | 不收回（軍閥的回合暫停，之後重新計 90 秒） |
