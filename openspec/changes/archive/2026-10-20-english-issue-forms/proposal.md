## Why

GitHub Discussions 改用英文經營，issue 表單也要一致改成英文，外部的人才看得懂。

## What Changes

- `.github/ISSUE_TEMPLATE/bug.yml`、`improvement.yml`、`config.yml` 的標題、說明、欄位和選項改成英文
- 遊戲下拉選單用「英文名 / 中文名」，例如 `Werewolf / 狼人殺`，玩家也對得上 Slack 裡的中文名稱；第一個選項是 `Lobby / other`
- 只改 repo 設定，遊戲行為不變，所以不寫 delta spec (`skip_specs`)
