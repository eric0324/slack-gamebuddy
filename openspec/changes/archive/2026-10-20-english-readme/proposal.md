## Why

全部遊戲都有英文版了，希望外國團隊也能用這個 bot；repo 的 README 是外部的人第一個看到的文件，改成全英文。

## What Changes

- README.md 全部改成英文：遊戲清單 (用程式裡的英文名稱、人數和介紹，和 bot 顯示的一致)、大廳和語言切換說明、社群連結、Slack app manifest (description 改英文)、執行和部署說明
- wiki 連結改成指向英文和繁體中文兩個語言首頁，不再逐一列出每款遊戲的中文頁面
- 只改文件，遊戲行為不變，所以不寫 delta spec (`skip_specs`)
